Confined Space Dashboard

Files:
- index.html — dashboard
- data.json — dashboard data
- Updated CS Identification all.xlsx — source workbook
- .github/workflows/update-data.yml — automatically regenerates data.json when the Excel file changes

For normal updates, replace only "Updated CS Identification all.xlsx" with the new workbook and commit it.
Do not add a file-upload control to the dashboard; users only see the published dashboard.
